# SceneSlot – Creative Studio Booking Platform

**Live Website:** [Add Live Website URL]

## Key Features

- Explore creative studios and browse by category.
- View studio details, pricing, location, and facilities.
- Add, edit, and delete studio listings.
- Upload studio images.
- Book studios and manage reservations.
- Prevent booking conflicts.
- User authentication with email/password and Google sign-in.
- Manage personal listings and bookings through the dashboard.
- Responsive design for all devices.

## Technology Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** Better Auth
- **Other Tools:** Swiper.js, Motion, Multer, Lucide React

## Local Setup

**1. Clone the repository**

```javascript
git clone YOUR_GITHUB_REPOSITORY_URL
cd SceneSlot
```

**2. Setup Backend**

```javascript
cd sceneslot-server
npm install
npm run dev
```

**3. Setup Frontend**

Open another terminal:

```javascript
cd sceneslot-client
npm install
npm run dev
```
